# 🎮 Nostalgia

אפליקציית Android בסגנון רטרו עם משחקים, מטבעות, חנות ומשחק אקראי.

## מה כלול

- ❌⭕ איקס־עיגול נגד המחשב.
- 🪙 ניצחון באיקס־עיגול = 50 מטבעות.
- 📺 פרסומת מדומה לפיתוח = 100 מטבעות.
- 🔒 פתיחת משחק חדש = 3,000 מטבעות.
- 🎲 משחק אקראי מתוך המשחקים שכבר פתוחים.
- 💾 שמירת יתרת המטבעות והמשחקים הפתוחים במכשיר.
- 🇮🇱 ממשק בעברית.

## פתיחה ב-Android Studio

1. שכפל את המאגר.
2. פתח את התיקייה `Nostalgia` ב-Android Studio.
3. בצע Gradle Sync.
4. הפעל את האפליקציה על Emulator או טלפון Android.

## GitHub Actions

המאגר כולל workflow ב-`.github/workflows/android.yml` לבנייה אוטומטית בכל push ל-`main` ובכל Pull Request.

## פרסומות אמיתיות

כפתור הפרסומת הוא כרגע סימולציה לצורך פיתוח. לפני הפצה אמיתית צריך לחבר ספק Rewarded Ads ולהגדיר את דרישות הפרטיות והמדיניות הרלוונטיות.
